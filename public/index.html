Jira Dependency Visualizer

Paste rows copied from a spreadsheet or Jira export to turn blocking relationships into a dependency graph. The bundled data is entirely synthetic and safe to copy, edit and paste back into the demo.

Jira-style spreadsheet rows

Copy cells from Excel or Google Sheets and paste them below. The first row must contain headers. Tab-separated spreadsheet data is preferred; quoted CSV is also accepted.

Supported columns

Friendly headers are Key, Summary, Status, Story Points, Group, Blocks and Blocked By. Common Jira export names such as Issue key, Story point estimate, Parent, Outward issue link (Blocks) and Inward issue link (Blocks) are also recognised.

Put multiple issue keys in a dependency cell separated by commas or semicolons.
